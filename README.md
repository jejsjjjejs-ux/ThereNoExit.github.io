# Личный поиск

## Страница и оформление
- index.html — разметка
- css/base.css — цвета, фон, общие правила (в том числе `[hidden]`)
- css/search.css — строка поиска, карточки файлов, просмотр картинок
- css/admin.css — админ-панель и вход
- css/showcase.css — архив записей слева/сверху и страница «досье»
- css/effects.css — анимации, свечение, мелочи
- bg.jpg — фоновая картинка

## Скрипты (порядок подключения см. в index.html)
- js/core.js — общие функции и ключ шифрования
- js/docs.js — показ .docx и текста (зачёркивание и чёрные полосы)
- js/auth.js — проверка пароля администратора (хранится только хеш)
- js/data.js — зашифрованные файлы и подсказки к паролям
- js/search.js — поиск, запрос пароля, показ файлов
- js/showcase.js — архив записей (#person-1…4), 8 персонажей (#character-1…8, открываются в новой вкладке: персонаж слева, ответ в «облачке» и 4 вопроса справа), страница досье, редактор карточек
- js/admin.js — шифрование файла в браузере (панель открывается по #admin)
- js/main.js — показ входа по #admin
- js/embers.js — искры на фоне
- js/lightbox.js — увеличение картинок
- cards.json — 12 карточек: первые 4 — архив записей, остальные 8 — персонажи. У персонажа: qa (вопросы и ответы, от 1 до 8), theme ("vn" — стиль визуальной новеллы, как у Алисы), bg (фон страницы)

## Утилиты
- add_file.py — добавить файл: `python add_file.py "фраза" файл` (`--inline` — встроить в страницу, `--password`, `--hint`).
  `python add_file.py --migrate` выносит встроенные файлы из data.js в vault/.
- vaultlib.py — общие функции шифрования для скриптов (нужен `pip install cryptography`)
- vault/ — зашифрованные файлы, по одному на каждый (до ~95 МБ)
- build.py — собирает всё в один build/index.html (cards.json вшивается автоматически)

## Размещение на GitHub Pages (или любом хостинге)
1. Создайте репозиторий и загрузите в него содержимое этой папки. Файлы больше 25 МБ загружайте через git, а не через веб-интерфейс GitHub.
2. Settings → Pages → Deploy from a branch → main / root.
3. Сайт открывается по адресу https://ИМЯ.github.io/РЕПОЗИТОРИЙ/. Открывать index.html напрямую с диска нельзя, браузер не даст загрузить файлы из vault/.
4. Новые файлы: `python add_file.py "фраза" файл`, затем загрузите в репозиторий js/data.js и новый файл из vault/.
5. Новые карточки архива: в админ-панели скачайте cards.json, замените им файл в репозитории, затем нажмите «Сбросить к опубликованным».

Для claude.ai (одной страницей) используйте режим `--inline`, файлы до ~10 МБ, и запускайте build.py. Файлы из vault/ в такую страницу не входят.
