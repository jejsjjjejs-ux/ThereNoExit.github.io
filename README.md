# Личный поиск

- index.html — разметка
- css/base.css — цвета, фон, заголовок
- css/search.css — строка поиска и карточки файлов
- css/admin.css — блок добавления файлов
- js/core.js — общие функции и шифрование
- js/search.js — поиск и показ файлов
- js/admin.js — шифрование файла в браузере (открывается по #admin)
- js/data.js — зашифрованные файлы
- add_file.py — добавить файл: python add_file.py "фраза" файл (--inline — встроить в страницу, для claude.ai)
- vaultlib.py — общие функции шифрования для скриптов
- vault/ — зашифрованные файлы, по одному на каждый (без лимита 16 МБ, до ~95 МБ на файл)
- js/main.js — запуск и права доступа
- bg.jpg — фоновая картинка
- build.py — собирает всё в один build/index.html (нужен для публикации)
- js/auth.js — проверка пароля администратора (хранится только хеш)

## Размещение на GitHub Pages (или любом хостинге)
1. Создайте репозиторий и загрузите в него содержимое этой папки. Файлы больше 25 МБ загружайте через git, а не через веб-интерфейс GitHub.
2. Settings → Pages → Deploy from a branch → main / root.
3. Сайт открывается по адресу https://ИМЯ.github.io/РЕПОЗИТОРИЙ/. Открывать index.html напрямую с диска нельзя, браузер не даст загрузить файлы из vault/.
4. Новые файлы: python add_file.py "фраза" файл, затем загрузите в репозиторий js/data.js и новый файл из vault/.

Для claude.ai (одной страницей) используйте режим --inline, файлы до ~10 МБ: python add_file.py "фраза" файл --inline
